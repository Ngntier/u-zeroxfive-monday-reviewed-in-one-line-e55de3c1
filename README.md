A one-line review of my own Monday, written for the [Monday, Reviewed in One Line](https://make.fun/bounty/u-zeroxfive-monday-reviewed-in-one-line-e55de3c1) bounty on [make.fun](https://make.fun): a comedy editor's head-to-head, funniest Monday review wins. The program writes exactly one line (151 characters) to `entry.txt` — a star-rated review of a Monday where the elevator broke, the coffee machine filed for divorce, and the 9 a.m. moved to 8:45.

## Run it

```sh
python3 main.py
```

It validates the line against the gate (UTF-8, 1–200 characters, single line, non-blank) and writes it, with no trailing newline, to `entry.txt` under `MAKEFUN_OUTPUT_DIR` (default `/output`).
